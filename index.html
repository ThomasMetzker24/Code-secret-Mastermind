    L’ART DE LA DÉDUCTION

    Chaque indice compte.

    Retrouvez les 4 couleurs dans le bon ordre en 10 essais. Le code est tiré au hasard parmi les 6 couleurs, avec répétitions possibles.

    Bien placée
    La bonne couleur, à la bonne place.

    Mal placée
    La bonne couleur, à une autre place.

    Chaque pion compte une seule fois. Les bien placés sont comptés en premier ; les indices ne désignent aucune case. Une proposition incomplète ne coûte aucun essai. Après dix essais sans victoire, la partie est perdue.

    Jouer au clavier

    Cliquez sur une case ou utilisez Tab pour la sélectionner. Choisissez une couleur avec les touches 1 à 6. Les flèches changent de case ; Retour arrière efface une case. Entrée valide la proposition lorsque vous composez le code.

    VOTRE PROCHAIN RACCOURCI

    Code secret, à portée de main.

    Retrouvez le jeu sur votre écran d’accueil, avec son nom et son icône. Après une première ouverture en ligne, vous pourrez aussi jouer hors connexion.

    Choisissez ci-dessous les étapes adaptées à votre appareil.

    iPhone et iPad

    Ouvrez ce site dans Safari. Dans le menu Partager, choisissez Sur l’écran d’accueil, puis Ajouter. Activez « Ouvrir comme app » si cette option est proposée.

    Android

    Ouvrez ce site dans Chrome. Touchez le bouton d’installation s’il apparaît, ou le menu ⋮, puis Installer l’application ou Ajouter à l’écran d’accueil.

    Sur ordinateur

    Dans Chrome ou Edge, utilisez le bouton d’installation ci-dessus ou l’icône d’installation dans la barre d’adresse. Sur Mac, Safari propose aussi Fichier → Ajouter au Dock selon sa version.

    La commande et son nom dépendent du navigateur. Si elle n’apparaît pas, le jeu reste utilisable dans cet onglet. L’installation ne conserve pas la partie : fermer ou recharger le jeu démarre une nouvelle énigme.

    Une nouvelle version est prête. Terminez votre partie avant de l’appliquer.
